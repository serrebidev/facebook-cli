# Credits

`fb` is Facebook and Messenger for LLM agents, as a single fast Rust CLI. It drives a dedicated Chrome profile that stays logged in to your Facebook account. Output is built for models: one record per line, tab separated, short refs instead of long URLs, no decoration.

The upstream project is [hieu-lee/facebook-cli](https://github.com/hieu-lee/facebook-cli). BlindFB work on top of it is reviewed upstream.
